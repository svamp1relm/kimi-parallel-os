# Рекомендуемые локальные проверки

Глобальные настройки не изменять автоматически. Пользователь может перенести нужные проверки в свою конфигурацию самостоятельно.

Рекомендуется блокировать или предупреждать о:

- `git commit --no-verify` и опасных `rm -rf`;
- изменении production-кода без обновления тестов;
- отсутствии `CLAUDE.md`/`AGENTS.md` при работе агента;
- незакоммиченных изменениях перед созданием worktree;
- выводе возможных секретов и debug statements;
- запуске параллельных задач с пересекающимися разрешёнными путями.

Для проекта без hook обязательный минимум перед завершением:

```bash
uv run pytest
uv run ruff check .
git diff --check
```
