# Git conventions

- Рабочие ветки создавать только по явной конфигурации задачи.
- Имя задачи использовать в имени ветки и worktree; не перезаписывать существующие.
- Одна задача — один логически изолированный набор изменений.
- В коммит не включать логи, секреты, state-каталоги, виртуальные окружения и test artifacts.
- Коммит выполняется только отдельным решением пользователя после зелёных проверок.
