# Безопасность

- Не читать, копировать или передавать секреты и токены.
- Использовать существующую авторизацию Kimi CLI, не реализовывать собственное хранение учётных данных.
- Разрешать процессам запись только в объявленные пути.
- Проверять, что проект и разрешённые пути не ведут за пределы выбранного workspace.
- Не выполнять команды из описания задачи как shell-код; передавать описание только аргументом `kimi -p`.
- Логи могут содержать чувствительные данные: не публиковать их без проверки.
